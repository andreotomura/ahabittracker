## Goal

Ship the requested in-app custom cursor using the recommended hybrid — a CSS
base plus an additive JS halo — degrading gracefully and without adding a
dependency or external asset.

## What was done

- **Base cursor (CSS only)** in `src/styles.css`: a neutral custom pointer
  (white disc + dark ring, centred hotspot) applied to `body` inside
  `@media (pointer: fine)`, with the built-in `auto` fallback. Text fields keep
  `cursor: text`. The image is an **inline SVG data URI** — single-file safe,
  no external asset.
- **Halo (JS flair)** in `src/js/ui.js` as `UI.initCursor()`: a themed, lagging
  accent that grows over interactive elements and contracts on press. Uses
  `--accent` so it follows every theme; `pointer-events: none`, `aria-hidden`,
  `z-index` above modals/toasts. Fires only on a **fine pointer without
  `prefers-reduced-motion`**.
- **Wiring**: `App.init()` calls `UI.initCursor()` after `bindEvents()`.
- **Never destructive**: the native cursor is never hidden (`cursor: none` is
  deliberately unused) — DECISIONS §18.
- **Version** → 0.9.0 (About + `package.json`).

## Key decisions & changes

- Hybrid over "replace the cursor": the CSS base works even where Safari ignores
  SVG cursors, and the JS halo is pure additive decoration — so a JS failure,
  touch device, or reduced-motion setting costs nothing.
- Halo positioning uses `translate3d` on an outer element and `transform: scale`
  on an inner dot, so the rAF follow and the CSS hover/press transitions don't
  fight each other.
- `matchMedia('(pointer: fine)')` (not coarse-detection) is the gate, plus the
  reduced-motion check.
- **DECISIONS §18** records the "never destructive" policy so this isn't
  re-litigated.

## Context dump

- Cursor entry points: base pointer is the `@media (pointer: fine) body { cursor:
  url(…) }` rule; the JS half is `UI.initCursor()` (called from `App.init()`).
- If you ever want per-theme cursor colours, the data URI colour can't read CSS
  vars — you'd add a `[data-theme="…"] body { cursor: url(…colour…) }` override.
- The halo's `INTERACTIVE` selector string lists what triggers the grow state;
  extend it when new actionable classes appear.
- Keep `cursor: none` out unless you *also* render a real pointer — §18.
- Version lives in `app.js` About + `package.json`; both bumped to 0.9.0.
