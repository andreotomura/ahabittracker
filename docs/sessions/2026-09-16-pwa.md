## Goal

Make the app installable and offline-capable for hosted deployments — without
breaking the core promise (one self-contained HTML file, zero dependencies) and
without adding a single npm package.

## What was done

- **DECISIONS §15** (logged with the work): PWA is an **additive build target**;
  `dist/index.html` stays the default portable artifact, `dist/pwa/` is the
  installable hosting variant.
- **Build tool** (`build.js`): refactored into `inlineHtml()` + `withoutPwa()` /
  `withPwa()`. Modes: `dev [dir]`, `build`, and new `pwa`. The dev server now
  accepts a directory (so `node build.js dev dist/pwa` previews the PWA) and
  serves `.webmanifest` with the right MIME type.
- **PWA assets** (`scripts/pwa.js`): `manifest()` (install metadata + 3 icons),
  `serviceWorker(version)` (app-shell precache, network-first navigations with
  offline fallback, cache-first assets, content-hashed cache name), and the
  injected `<head>` snippet (manifest link, theme-color pair, apple-touch meta,
  protocol-guarded SW registration).
- **Icons** (`scripts/icons.js`): a **hand-rolled PNG encoder** (CRC32 + zlib)
  that rasterizes the gradient+check brand mark with 2× supersampling —
  rounded-square 192/512 plus a full-bleed maskable 512. Pure functions.
- **Markup** (`src/index.html`): a `<!--PWA-->` marker the plain build strips
  and the PWA build replaces.
- **Scripts/version**: `build:pwa`, `preview:pwa`; version → 0.6.0.
- **Tests** (`scripts/smoke.js`): PNG signature + IHDR dimensions, manifest
  install fields, SW handlers/cache name, PWA head snippet.

## Key decisions & changes

- Two artifacts, one source: `npm run build` = single file (no PWA hooks, no
  external refs), `npm run build:pwa` = same inlined HTML + sidecars.
- Icons are generated, not committed — `dist/` remains a build artifact and the
  repo stays dependency-free.
- SW version = short SHA1 of the built HTML, so any change propagates.
- **Theming backlog recorded** per the user's request: multi-theme system with a
  new-brutalist direction (see ROADMAP “Backlog idea: theming system”).

## Context dump

  injected head tags, put them in `PWA_HEAD` (`scripts/pwa.js`), not the shell.
