## Goal

Take the three flagged areas — modal animations, empty states, and
first-run onboarding — and give the app the "joy to open" feel the vision
promises, with zero schema changes and no new dependencies.

## What was done

- **Onboarding** (`src/js/render.js`, `src/js/app.js`):
  - Dismissible **welcome card** on Today with three tips (check-in / notes /
    Stats). Shows only when there's ≥ 1 active habit (the Today empty state
    already covers "no habits").
  - Dismissal is **UI-only state**, `localStorage['ahabit.welcome.v1']`
    (DECISIONS §14) — never exported/imported. `App.showWelcome()/
    dismissWelcome()`; `Render.renderToday(showWelcome)` keeps Render pure.
- **Empty states**:
  - Stats with no active habits → one friendly empty card (heatmap still shown
    if archived history exists — `heatmapCard()` extracted as a pure helper).
  - Day modal with no habits → proper empty state + "＋ Add habit" CTA (which
    seamlessly swaps the modal to the editor via the existing `add` action).
  - Calendar shows "No check-ins this month — tap a day to backfill" on empty
    months.
- **Modal motion** (`src/js/ui.js` + CSS): `openModal` adds a one-shot
  `.modal-enter` class → gentle body fade-up. `updateModal` (picker refreshes)
  deliberately does **not**, so emoji/color/target clicks never flicker.
- **Micro-polish** (CSS): hover lift on stat/health cards, staggered
  health-card entrance (per-card `--i`, capped at 210 ms), compact empty class,
  responsive welcome card.
- **Version** bumped to **0.5.0** (About dialog + `package.json`).
- **Tests** (`scripts/smoke.js`): welcome shown/dismissed/shown-via-flag,
  Stats single empty state (no charts), calendar + day modal render with no
  habits, sample data reloads.

## Key decisions & changes

- Onboarding state lives outside the DB (DECISIONS §14) — importing a backup
  won't re-show or suppress the card; it's per-browser like the theme.
- Empty/zero-data views consolidate to a single friendly message instead of a
  dashboard of zeros (Stats being the big win).
- Enter animation is scoped to `openModal` so it doesn't replay on `updateModal`.
