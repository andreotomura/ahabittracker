Notes

• The mark geometry lives in scripts/icons.js (raster) and the same path is inlined in src/index.html for the topbar and favicon.
• Variant “Accent H” is a one-line colour change; “Bold” is stroke-width 9 vs 7; “Mono” drops the gradient tile.
• Within the app the tile background is var(--grad) and the strokes use currentColor, so every theme recolours the logo automatically.
